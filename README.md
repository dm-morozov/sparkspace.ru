# SparkSpace

Многостраничный сайт разработки, продвижения и автоматизации бизнеса.

## Структура

- `design/` — исходники генератора HTML, стили, сценарии и изображения.
- `tools/build_public.py` — публичная статическая сборка.
- `deploy/` — отдельный контейнер Nginx и конфигурация домена.

## Сборка

```sh
python tools/build_public.py
```

Результат: `dist/public/` и `dist/sparkspace-static.zip`. Для сборки достаточно Python 3.11+ без сторонних пакетов.

Публичная сборка содержит прямые контакты вместо локальной формы. Python API, база данных, черновики согласий и рабочие материалы не публикуются. Локальная версия в `design/` сохраняет тестовый режим.

## Размещение

Исходники хранятся в GitHub. Статические файлы обслуживаются отдельным контейнером на Selectel, домен и DNS управляются на Beget. Инструкция: `deploy/README.md`.

## Проверка перед выпуском

- [Приёмка интерфейса](tools/QA-CHECKLIST.md): конкретные состояния, устройства и отдельные локальные/публичные результаты.
- [Реестр изображений](tools/ASSET-REGISTRY.md): источники, даты, размеры, варианты и контроль изменений. Для этой дополнительной проверки нужен Python с Pillow; сама сборка по-прежнему не требует сторонних пакетов.
- [Сборка стилей](tools/CSS-BUNDLE.md): явный порядок CSS-компонентов и сохранение утверждённого каскада.
- [Задачи и журнал](Задачи.md): выполненные пакеты, оставшиеся проверки и ограничения.
