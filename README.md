# SparkSpace

## Проверка изменений

Обычная сборка по-прежнему требует только Python 3.11+:

```sh
python tools/build_public.py
python design/check_pages.py
```

Для браузерной приёмки дополнительно нужны Playwright и установленный Google Chrome:

```sh
python -m pip install playwright
python tools/check_browser.py --output .qa/browser
```

Проверка запускает временный сервер на loopback, сохраняет снимки и `report.json`,
проверяет 1440/1180/390/320 px, клавиатуру, повторные действия, контекст услуги и
reduced-motion. Внешние контакты не активируются, сообщения не отправляются.
Для другого Chromium можно передать `--executable /path/to/browser`.

Адаптивные изображения уже сохранены в репозитории. Обновление вариантов требует
Pillow и команды `python tools/optimize_images.py`; это отдельный инструмент
подготовки, не зависимость публичной сборки. Карта вариантов находится в
`tools/responsive_images.json`, происхождение новых иллюстраций в
`design/service-art.json`. Исходные PNG сохраняются; в релиз входят WebP 480/960 px.

Многостраничный сайт разработки, продвижения и автоматизации бизнеса.

## Структура

- `design/` — исходники генератора HTML, стили, сценарии и изображения.
- `tools/build_public.py` — публичная статическая сборка.
- `deploy/` — отдельный контейнер Nginx и конфигурация домена.

## Сборка

```sh
python tools/build_public.py
```

Результат: `dist/public/` и `dist/sparkspace-static.zip`. Для сборки достаточно Python 3.11+ без сторонних пакетов.

Публичная сборка содержит прямые контакты вместо локальной формы. Python API, база данных, черновики согласий и рабочие материалы не публикуются. Локальная версия в `design/` сохраняет тестовый режим.

## Размещение

Исходники хранятся в GitHub. Статические файлы обслуживаются отдельным контейнером на Selectel, домен и DNS управляются на Beget. Инструкция: `deploy/README.md`.

## Коммиты

Conventional Commits: `feat:`, `fix:`, `docs:`, `build:`, `chore:`. Описание отражает внесённое изменение, например `feat: добавлена страница приложений`.
